# google-playstore-eda

Project Overview
This project performs Exploratory Data Analysis (EDA) on the Google Play Store dataset to uncover insights about app ratings, installs, pricing, and category performance. The objective was to clean the dataset, analyze trends, and extract meaningful business insights using Python.
~Tools & Technologies Used
-Python
-Pandas
-NumPy
-Matplotlib
-Seaborn
-Google Colab
Dataset Information
The dataset contains information about 10,000+ Google Play Store apps including App Name, Category, Rating, Reviews, Installs, Type (Free/Paid), Price, Content Rating, and Genres.
Dataset Source: Public Google Play Store dataset (originally shared by krishnaik06).
~Data Cleaning Steps Performed.
-Removed duplicate entries
-Handled missing values
-Converted installs and price columns into numeric format
-Cleaned inconsistent data entries
~Exploratory Data Analysis Performed
-Distribution of app ratings
-Category-wise app count analysis
-Free vs Paid app comparison
-Installs vs Rating analysis
-Correlation heatmap
-Most popular app categories
Key Insights
Majority of apps are free
Most ratings lie between 4.0 – 4.5
Certain categories dominate total installs
Weak correlation between rating and installs
Conclusion
This project demonstrates practical skills in data cleaning, exploratory data analysis, data visualization, and insight extraction. It reflects the ability to transform raw data into meaningful insights using Python.
